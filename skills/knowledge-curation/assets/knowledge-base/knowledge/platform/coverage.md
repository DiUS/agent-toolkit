# Platform coverage

> **The honesty artefact.** Consult this before any analysis. Its job is to make
> ignorance visible — a domain absent from this table is worse than a domain marked
> `unknown`, because absence is indistinguishable from irrelevance.
>
> Non-negotiable: if a request touches anything not `curated`, flag it as
> out-of-knowledge rather than reasoning about it (`ba-principles.md` rule 1).
