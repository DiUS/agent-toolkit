# Platform constraints

Invariants true across the **whole platform** — one file per constraint
(`CN-<NNN>.md`). A constraint is added only when a source states one; never invented
to fill a gap. Invariants scoped to a single domain live under
`domains/<domain>/constraints/` instead, and an invariant scoped to one feature is a
rule, not a constraint.

Ships empty. Template: the knowledge-curation skill's
`references/knowledge/constraint.md`.
